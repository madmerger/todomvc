# TodoMVC E2E テストケース（app-spec.md 準拠）

対象アプリ: `examples/javascript-es6`（UI は日本語）

## 事前準備

```bash
cd examples/javascript-es6
npm install
npm run build && npm run serve   # http://localhost:7002
```

UI 用語対応:

| 要素 | 表示 |
| --- | --- |
| 新規入力欄 | `何をする必要がありますか？` |
| 一括完了 | 入力欄左の矢印 / `すべて完了にする` |
| フィルター | `すべて` (`#/`) / `未完了` (`#/active`) / `完了` (`#/completed`) |
| 完了削除ボタン | `完了したタスクを削除` |
| 残件表示 | `残り N 件` |

注意: このアプリの永続化はメモリー内 (`memoryStorage`) のため、リロードでデータが消えます。TC-13 以外ではシナリオ中にリロードしないこと。

---

## TC-01 初期表示（todo が無い状態）

1. `http://localhost:7002` を開く。

期待値:
- `.main`（リスト部）と `.footer`（件数・フィルター）が非表示。
- 新規入力欄にフォーカスが当たっている（autofocus）。

## TC-02 todo の追加

1. 入力欄に `牛乳を買う` と入力し Enter。
2. 続けて `本を読む`、`散歩する` を追加。

期待値:
- 3 件が追加順（上から 牛乳を買う → 本を読む → 散歩する）で並ぶ。
- 追加のたびに入力欄が空になる。
- `.main` と `.footer` が表示され、`残り 3 件` と表示される。

## TC-03 空文字・空白のみの入力は無視される

1. 入力欄で Enter だけ押す。
2. 半角スペースのみを入力して Enter。

期待値:
- todo は追加されない（件数が変わらない）。

## TC-04 前後の空白はトリムされる

1. `  会議の準備  ` と入力して Enter。

期待値:
- `会議の準備` として追加される（前後の空白なし）。

## TC-05 単一 todo の完了 / 未完了切り替え

1. `本を読む` のチェックボックスをクリック。

期待値:
- 行の `<li>` に `completed` クラスが付き、取り消し線で表示される。
- 残件表示が `残り 2 件` になる。
- 再度クリックすると未完了に戻り、`残り 3 件` に戻る。

## TC-06 カウンターの単数・複数（日本語は固定表記）

1. todo を 0 / 1 / 2 件の未完了状態にする。

期待値:
- それぞれ `残り 0 件` / `残り 1 件` / `残り 2 件` と表示され、数字が `<strong>` で囲まれている。

## TC-07 すべて完了にする（一括トグル）

1. 入力欄左の一括トグルをクリック。

期待値:
- すべての todo が完了になり、`残り 0 件` になる。
- もう一度クリックするとすべて未完了に戻る。
- 個別に 1 件だけ未完了に戻すと一括トグルのチェックが外れ、全件完了にすると再びチェックが入る。

## TC-08 todo の編集（Enter で保存）

1. `牛乳を買う` のラベルをダブルクリック。
2. 内容を `牛乳と卵を買う` に変更し Enter。

期待値:
- ダブルクリックで `<li>` に `editing` クラスが付き、編集用 input に既存タイトルが入りフォーカスされる。
- Enter で保存され `editing` クラスが外れ、タイトルが `牛乳と卵を買う` になる。

## TC-09 編集を blur で保存

1. ラベルをダブルクリックし、内容を変更してリスト外をクリック。

期待値:
- 変更が保存され、編集モードが解除される。

## TC-10 編集を Escape で破棄

1. ラベルをダブルクリックし、内容を変更して Escape。

期待値:
- 変更は破棄され元のタイトルのまま、編集モードが解除される。

## TC-11 編集で空にすると削除される

1. ラベルをダブルクリックし、内容をすべて消して（または空白のみにして）Enter。

期待値:
- その todo が一覧から削除される。

## TC-12 todo の削除（×ボタン）

1. 行にマウスを重ねる。
2. 表示された `×`（`.destroy`）をクリック。

期待値:
- ホバー時のみ `×` が表示される。
- クリックで該当 todo が削除され、残件表示が更新される。

## TC-13 完了したタスクを削除

1. 2 件を完了状態にする。
2. `完了したタスクを削除` をクリック。

期待値:
- 完了済み todo だけが削除され、未完了は残る。
- 完了済みが 0 件のときはボタンが非表示。
- クリック後、一括トグルのチェック状態が解除される。

## TC-14 フィルター: すべて / 未完了 / 完了

1. 未完了 1 件・完了 1 件の状態を作る。
2. `未完了` をクリック → `完了` をクリック → `すべて` をクリック。

期待値:
- URL がそれぞれ `#/active`、`#/completed`、`#/` になる。
- 表示される todo が対応する状態のみになる。
- 選択中のフィルターリンクに `selected` クラス（枠線）が付く。

## TC-15 フィルター中の状態更新

1. `未完了` フィルター表示中に、表示中 todo のチェックボックスをクリック。

期待値:
- 完了になった todo が一覧から即座に消え、残件表示が減る。
- `完了` フィルターに切り替えるとその todo が表示される。

## TC-16 URL 直接指定でのルーティング

1. アドレスバーに `http://localhost:7002/#/completed` を直接入力して開く。

期待値:
- 完了フィルターが選択された状態で表示される。
- 注意: このアプリは永続化がメモリー内のため、リロードを伴うと todo データ自体は消える。

## TC-17 永続化（仕様上の期待値 / 既知の差分）

1. todo を数件追加し、ページをリロード。

app-spec.md の期待値:
- `todos-[framework]` キーで localStorage に永続化され、リロード後も todo が残る。

実装の現状:
- `src/store.js` がメモリー内ストレージのため、リロードで todo が消える → **仕様との差分（既知）**。
