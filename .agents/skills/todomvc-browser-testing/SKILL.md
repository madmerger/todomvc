# TodoMVCブラウザーテスト

## 起動
- リポジトリーのルートで`npm run server`を起動する。標準ポートは8000、静的配信対象はリポジトリー全体。
- サイトは`http://localhost:8000/index.html`、アプリは`http://localhost:8000/examples/javascript-es6/dist/`。
- `dist`と依存パッケージが既に存在するか確認する。ソース変更後は既存distが古い可能性があるため、必要ならアプリディレクトリーのbuildスクリプトで再構築する。
- サイトは`bower_components`内のスクリプト・CSSも参照する。ルートページの表示確認では、それらの存在とコンソールの読み込みエラーも確認する。

## UIでの確認
- サイトのExamplesからアプリへ移動し、3件を異なる名前で追加して上から追加順であることを確認する。
- 編集はラベルをダブルクリックし、入力後Enter。削除は行にマウスを重ねて表示される×。
- 完了操作は各行の見えるチェックボックス、一括操作は入力欄左の矢印を使う。
- 完了判定はチェックだけでなく、取り消し線、残件数、Active/Completedの表示、Clear completedの結果を組み合わせる。
- フィルターはハッシュルート`#/`、`#/active`、`#/completed`。URLと選択枠も確認する。
- 保存がメモリー内の実装では再読み込みでデータが消えるため、一連のシナリオ中にページを再読み込みしない。
- 自動テストで報告された不具合がGUI操作で再現しなくても、操作経路の差を明記し、自動テストの問題が解消したとは主張しない。

## Devin Secrets Needed
なし。ローカル静的サイトにはログイン不要。
